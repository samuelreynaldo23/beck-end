Java é uma linguagem de programação de alto nível, orientada a objetos e fortemente tipada, criada pela Sun Microsystems em 1995 e mantida atualmente pela Oracle.

Filosofia Principal: "Escreva uma vez, execute em qualquer lugar"
O código Java não é compilado diretamente para a linguagem da máquina local, mas sim para bytecode. Esse bytecode é interpretado pela JVM (Java Virtual Machine), permitindo que o mesmo sistema rode em Windows, Linux ou macOS sem ajustes no código.

Principais Características

Orientação a Objetos: Tudo é estruturado em classes e objetos, favorecendo reuso, modularização e manutenção.

Gerenciamento de Memória: Possui Garbage Collector automático, que limpa da memória os objetos não mais utilizados para evitar vazamentos (memory leaks).

Segurança e Robustez: Não permite manipulação direta de ponteiros de memória e conta com forte checagem de tipos em tempo de compilação.

Onde é Utilizada

Sistemas Corporativos: Back-end de bancos, e-commerces e grandes plataformas devido à alta confiabilidade.

Microserviços e Web: APIs escaláveis construídas com ecossistemas como Spring Boot.

Desenvolvimento Mobile: Base histórica do sistema Android (embora compartilhe espaço com o Kotlin hoje).

Big Data: Infraestruturas pesadas de processamento de dados, como Apache Hadoop e Spark.
